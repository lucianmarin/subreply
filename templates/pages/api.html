About API Directory Privacy Terms

Build your own native client for iOS, Android, desktop or the web with the Subreply API. Third-party apps are encouraged to adopt the "sub" or "reply" naming convention — such as Subchat, Sublevel, Subversion or Macreply — and can extend the core experience with features like inline media previews, instant translation and custom notifications.

Authenticate by requesting a token from the /api/login endpoint and passing it in the Authorization: Bearer header on subsequent requests. Paginate any GET endpoint by appending the ?p=number query parameter.

GET Endpoints

  • /api/feed
  • /api/following
  • /api/followers
  • /api/mentions
  • /api/replies
  • /api/saved
  • /api/people — optional q param to search people
  • /api/discover — optional q param to search content
  • /api/trending
  • /api/messages
  • /api/notifications
  • /api/reply/{id:int}
  • /api/{username}/message
  • /api/{username}/posts
  • /api/{username}

POST Endpoints

  • /api/login — username*, password* params; returns token and user
  • /api/register — username*, email*, password1*, password2*, first_name, last_name, emoji, birthday, location params; returns token and user
  • /api/thread — content* param; returns thread details
  • /api/reply/{id:int} — content* param; returns reply details
  • /api/{username}/send — content* param; returns message details

PATCH Endpoints

  • /api/edit/{id:int} — content* param; returns reply details
  • /api/profile — username*, email*, first_name, last_name, emoji, birthday, location, link, description params; returns user
  • /api/details — github, instagram, linkedin, reddit, paypal, spotify, x, code, number params; returns user

POST Actions

  • /api/unsend/{id:int}
  • /api/{username}/clear
  • /api/delete/{id:int}
  • /api/save/{id:int}
  • /api/unsave/{id:int}
  • /api/follow/{username}
  • /api/unfollow/{username}
